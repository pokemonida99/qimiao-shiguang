# 棲渺拾光 ‧ 燈下資料館

《黃泉燒肉店》的粉絲整理站。手機優先，深色燈籠夜色，四個主要區塊：
**劇情線 / 人物誌（含關係圖）/ 詞彙資料庫 / 製作雜談**。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體（版型 + 程式）。開發時直接開這個。 |
| `data.js` | **唯一需要編輯的檔案**。所有劇情、人物、詞彙、關係、雜談都在這裡。 |
| `assets/` | 從 `../黃泉燒肉店/` 的官方圖文卡裁切出來的乾淨畫面。 |
| `build.py` | 打包成單一 HTML（圖片內嵌）。 |
| `棲渺拾光-燈下資料館.html` | 打包好的單檔版，可直接雙擊開啟、或丟到任何空間。 |

## 本機預覽

```
python3 -m http.server 4173 --directory .
```
然後開 http://localhost:4173

改完 `data.js` 重新整理就會更新，不需要任何建置流程。
要重新打包單檔版：`python3 build.py`

## 怎麼補資料

`data.js` 裡每一筆都有 `status`：

- `"canon"` — 已有官方出處，網站正常顯示
- `"pending"` / `"partial"` — 網站會顯示成「檔案封存中」「檔案未完整」的封存樣式

### 補分集（最缺的一塊）

在對應季度的 `episodes: []` 裡加：

```js
episodes: [
  { no: 1, title: "第一位客人", one: "一句話梗概（會顯示在時間軸上）",
    tags: ["遺憾", "單元劇"], url: "https://www.instagram.com/p/xxxx/" },
]
```

### 補人物

`characters` 陣列。沒有公開定裝照就把 `art` 留成 `""`，網站會自動改用剪影版面，
不會硬套一張不確定是誰的劇照。

### 補關係線

`relations` 陣列，`type` 可用 `love / bond / rival / divine / duty`，
`status: "canon"` 是實線、其他是虛線。

## 站台原則

沒有出處的劇情一律不寫。所有「已確認情報」都能在 `../黃泉燒肉店/索引.md` 找到原文。
